# Development log — October 2026

## 2026-10-28 — The repository

**Done:** The repository, with the project's conventions: `AGENTS.md`, `CLAUDE.md`, `CONTRIBUTING.md`, the `adr`, `devlog` and `review` checklists, the templates. ai-platform is pinned at `platform/`.

**Decisions:**
- [ai-platform ADR-0001](https://github.com/trungnguyen278/ai-platform/blob/main/docs/decisions/0001-repositories.md), accepted: the repositories are a family, `ai-<what it is>`, and this one is the cloud side of every device.
- [ADR-0001](../decisions/0001-architecture.md), proposed: a modular monolith, with ports and adapters, in three process roles (`api`, `agent`, `worker`); cost is part of the architecture. Drawn from Luni Cloud, the preview, and from Shopify, Home Assistant and xiaozhi-esp32-server ([architecture](../architecture.md)).
- [ADR-0002](../decisions/0002-stack.md), proposed: Python, with LiveKit Agents for conversations and FastAPI for requests. LiveKit's turn detector has no Vietnamese, which the pipeline must make up for.

**Problems / unfinished:** No code yet. The repository is private for now.

**Next:**

- The conversation pipeline: speech recognition, the language model and speech synthesis, or a speech-to-speech model. It must handle Vietnamese, mixed with English, first, and more languages later ([ai-platform ADR-0002](https://github.com/trungnguyen278/ai-platform/blob/main/docs/decisions/0002-languages.md)).
